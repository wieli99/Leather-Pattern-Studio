# User manual

Leather Pattern Studio is a precision 2D editor. Dimensions use millimetres. Projects stay on your device.

Start with [your first pattern](#getting-started), explore [drawing tools](#drawing), or consult the [keyboard reference](#shortcuts).

- [Stitch lines](#stitching): place, configure, merge, and split attached stitching.

- [Indicators](#indicators): arrows, crosshairs, and dimensioned size guides.
