# User manual

Draw accurate leather patterns, add stitching, and print them at actual size. Projects stay on your device; save project files regularly.

Start with [your first pattern](#getting-started), from an exact rectangle to a checked print.

- **Draw accurately:** [drawing tools](#drawing), [numeric dimensions and snapping](#measurements).
- **Change a pattern:** [selection and curve editing](#selection), [move, rotate, resize, round, trim and merge](#transforms).
- **Mark leather work:** [skiving, glueing, cutout patterns and outline appearance](#measurements/area-and-appearance).
- **Prepare stitching:** [placement, spacing, continuous lines and matching hole counts](#stitching).
- **Label your work:** [text](#text), [arrows and size guides](#indicators).
- **Prepare paper patterns:** [print layouts and export](#printing).
- **Keep your work:** [save, reopen, recovery and offline use](#files).
- **Find a control:** [workspace](#workspace), [keyboard shortcuts](#shortcuts), [troubleshooting](#troubleshooting).
