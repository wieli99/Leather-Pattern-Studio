# Text and objects

Choose Text (T), then click to place a label. Double-click existing text to edit it. Enter adds a line; Ctrl/⌘+Enter applies; Esc cancels. Clicking outside also applies. Empty text removes an existing label when applied.

Properties edits text and font size. The selection box automatically fits the updated text, including multiple lines, while keeping its starting point fixed. Text shapes support selection and transforms. Object names are separate from text contents.

Rename through double-click or F2 in the Objects list. Enter or leaving the name field applies; Esc cancels.

Trim and Stitch line are disabled when only text is selected, including their keyboard shortcuts. With a mixed selection, these tools remain available for compatible outlines. Locked selections keep these tools disabled.
