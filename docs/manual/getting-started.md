# Your first pattern

New projects open on an empty canvas. Choose a drawing tool from the left toolbar to begin.

![Empty canvas in a new project](/manual/images/empty-canvas.png)

1. Choose Rectangle (R).
2. Click the first corner, then the opposite corner.
3. Press Esc to return to Select and click the outline.
4. Enter exact Width and Height in Properties. Press Enter to apply each field.
5. Choose Move (G), enter values, and press Apply.
6. Save with Ctrl/⌘+S. Keep the saved file: browser recovery is separate.

Use the hints below Properties for controls available in the current context.
